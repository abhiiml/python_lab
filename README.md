## 🚀 How to Run

### Prerequisites
- Python 3.8 or higher
- NumPy (`pip install numpy`)
- PyTTSx3 (optional, for voice assistant: `pip install pyttsx3`)

### Execution
Run any script using Python:
```bash
python ch6_prb.py
python assignments/q01_calculator.py
python assignments/numpy_2d_array.py
```
